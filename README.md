# QuRa — Птичий двор

Браузерный прототип v0.3 survival-рогалика. Одна курочка, три слота оружия, десять минут до успешного забега и бесконечная бонусная волна после.

## Запуск

Нужен Node.js 20 или новее. Зависимости устанавливать не нужно.

```sh
node server.mjs
```

Открыть http://localhost:4173. Не открывать index.html напрямую: игра использует ES-модули. Сервер доступен только на этом компьютере. Для статического хостинга достаточно index.html, style.css, game.js и engine.js.

## Баланс v0.2

Больше медленных врагов на старте, сниженная скорость курочек и снарядов, более редкие выстрелы белок, увеличенный клевок. Добавлены магнит (0,5%), защита после выбора уровня, пассивки размера атак и опыта. Все пассивки работают со сложными процентами. На каждом уровне оружия растут урон, скорость атак, размер и количество снарядов. Точные числа — в BALANCE.md.

## Управление

- WASD или стрелки — движение. На сенсорном устройстве — джойстик слева внизу.
- Атака автоматическая по ближайшему противнику.
- Esc или кнопка — пауза. При потере фокуса игра автоматически останавливается.
- Карточки усилений — мышь/касание либо клавиши 1, 2, 3.
- Звук включается отдельно. Рекорд сохраняется в localStorage, если браузер разрешает.

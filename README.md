# QuRa — Птичий двор

## Актуальная версия · 12 ноября 2026

**Последняя версия из чата «Прототип птичий двор» находится в [`releases/2026-11-12/`](releases/2026-11-12/).**

Серверному агенту: начать с [инструкции переноса](docs/SERVER_HANDOFF_2026-11-12.md), затем прочитать [README комплекта](releases/2026-11-12/README.md).

Комплект содержит готовый клиент, графику, выбранные звуки, утверждённый микс, ползунок громкости с исходным уровнем на 30%, соответствующий серверный replay-модуль, баланс и SHA-256 всех файлов. Демо API, тестовая экономика и звуковые пульты не включены в клиент.

Проверка (Node.js 20+, без установки зависимостей):

```sh
node releases/2026-11-12/verify.mjs
```

Результат: 791 проверенный файл, протокол `poultry-v3-20261107`, совпадение replay клиента и серверного модуля на 3000 тиках. В исходном проекте прошли 107 тестов.

**Это кандидат для интеграции.** Действующая игра и backend находятся в `gselfman/QuRa`. Перед выкатом серверный агент должен подключить новый протокол, закрепить версию движка и баланс, проверить API и обратную совместимость активных сессий. Комплект намеренно сохраняет `activationReady=false`. Production в ходе подготовки не изменялся.

Файлы в корне этого репозитория ниже относятся к старому прототипу v0.8; команды из исторического описания не собирают актуальный комплект.

## Историческое описание прототипа v0.8

Браузерный survival-рогалик v0.8. Три персонажа, три слота орудий, цель 10 минут и бесконечная бонусная волна.

Новое: [мультяшные животные и атаки, последовательный клевок, плавные рывки лис и звук](docs/VERSION_06.md).

[Лаборатория баланса 0.7](docs/VERSION_07.md): пульт настройки под игровым полем.

## Запуск

Node.js 20+, без установки зависимостей:

```sh
node server.mjs
```

Открыть http://localhost:4173. Нельзя запускать index.html напрямую: используются ES-модули. Для статического хостинга выполните `npm run build` и загрузите содержимое `build/`. Каталог содержит все необходимые модули, шрифты, графику и галерею спрайтов `assets.html`.

## Новое в v0.5

Монах с чередованием крыльев и топота, две эволюции, бонусы всех героев за уровни. Воскрешение один раз за 20 тестовых GE до 10-й минуты. Бесплатные перебросы на каждом пятом уровне копятся до конца забега. Пассивка снарядов ограничена тремя выборами. Спавн плавно меняет состав, не удаляя старых врагов. Новая объёмная графика по референсам QuRa, движения существ и отдельные анимированные рисунки атак.

## Управление

WASD или стрелки, на телефоне джойстик. Атака автоматическая. Esc — пауза с характеристиками и статистикой. Карточки — мышь/касание или 1, 2, 3. При скрытии вкладки игра останавливается. Звук включён при старте; кнопка сверху сохраняет выбор вкл./выкл.

# QuRa — Птичий двор

Браузерный survival-рогалик v0.7. Три персонажа, три слота орудий, цель 10 минут и бесконечная бонусная волна.

Новое: [мультяшные животные и атаки, последовательный клевок, плавные рывки лис и звук](docs/VERSION_06.md).

[Лаборатория баланса 0.7](docs/VERSION_07.md): пульт настройки под игровым полем.

## Запуск

Node.js 20+, без установки зависимостей:

```sh
node server.mjs
```

Открыть http://localhost:4173. Нельзя запускать index.html напрямую: используются ES-модули. Для статического хостинга нужны index.html, style.css, game.js, engine.js, render.js, projectile.js, sound.js и assets.

## Новое в v0.5

Монах с чередованием крыльев и топота, две эволюции, бонусы всех героев за уровни. Воскрешение один раз за 20 тестовых GE до 10-й минуты. Бесплатные перебросы на каждом пятом уровне копятся до конца забега. Пассивка снарядов ограничена тремя выборами. Спавн плавно меняет состав, не удаляя старых врагов. Новая объёмная графика по референсам QuRa, движения существ и отдельные анимированные рисунки атак.

## Управление

WASD или стрелки, на телефоне джойстик. Атака автоматическая. Esc — пауза с характеристиками и статистикой. Карточки — мышь/касание или 1, 2, 3. При скрытии вкладки игра останавливается. Звук включён при старте; кнопка сверху сохраняет выбор вкл./выкл.

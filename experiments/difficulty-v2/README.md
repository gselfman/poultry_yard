## Запуск

Node.js 20+, без установки зависимостей:

```sh
cd experiments/difficulty-v2
npm start
npm test
```

Адрес: `http://127.0.0.1:4175`. Для проверки событий без ожидания: `http://127.0.0.1:4175/?qa=1`. Кнопки проверки работают только во второй сложности; обычный адрес их не показывает. `npm run build` собирает самостоятельный статический клиент в `dist/` с исходной графикой и утверждёнными звуками.

Текстовые модули скопированы из точного комплекта от 12 ноября для изоляции лаборатории; графика переиспользуется из него через `<base>`, без повторного хранения бинарных файлов.

## Режимы

| Параметр | I · Обычный двор | II · Дикий двор |
|---|---:|---:|
| HP всех врагов, включая боссов | ×0,90 | ×1,00 |
| Скорость всех врагов, кроме волков | ×0,90 | ×1,00 |

Множители действуют поверх ноябрьского баланса, прогрессии и бонусной волны. Глобальные `ENEMIES` при выборе не мутируются: повторные старты не накапливают проценты. Первая сложность фиксируется на этой базе; события развиваются во второй.

## События: рабочие значения первой проверки

Точные прежние параметры в найденных документах не обнаружены. Владелец уточнил: охота — стая волков; ядерное событие — скорее бонус. Интервалы и эффекты ниже — **новые рабочие значения для тестирования**, не восстановленные старые договорённости. Настройки собраны в `client/world-events.js` → `EVENT_RULES`.

| Событие | Первый запуск / повтор | Длительность | Поведение |
|---|---|---|---|
| Ночь | 2:00 / каждые 3 минуты | 45 с | Враги ×1,10 HP и скорости, включая рывки боссов. Новые враги тоже усилены. Доля оставшегося HP сохраняется: рассвет/закат не лечат. |
| Дождь | 1:15 / каждые 2:30 | 30 с | Девять луж около игрока; курочка внутри медленнее на 15%. Используется уже существующий бонус дождя: быстрее выпадают лечебные червячки. |
| Охота | 3:20 / каждые 3 минуты | 25 с | Предупреждение за 5 с. Шесть дополнительных волков с интервалом 2 с. Обычная логика стаи и параметры сложности/ночи. Пришедшие волки остаются до победы над ними. Лимит врагов соблюдается. |
| Ядерная поддержка | 2:50 / каждые 3:30 | Предупреждение 5 с | Уничтожает обычных врагов на карте, очищает вражеские жёлуди. Босс теряет до 25% максимального HP, остаётся минимум 1 HP. Обычный опыт/очки за убийства. Курочка не получает урона. |

События могут пересекаться. Таймеры и анимации идут по активной симуляции; пауза, выбор усиления/эволюции и итоговые экраны их останавливают. Ночь затемняет края, сохраняя читаемость вокруг курочки. Нет сплошной белой вспышки.

## Недостающие ассеты

Рабочая версия не заблокирована: ночь, дождь, лужи, предупреждение и удар рисуются программно; волки используют утверждённые кадры. Прежние звуки и микс сохранены.

1. **Ядерный удар QuRa:** прозрачный атлас 8 кадров 512×512, кольцо и мультяшное грибовидное облако, единые центр и масштаб, без текста/фона. Иконка события 192×192. Это событие, а не новое орудие сборки.
2. **Дождь:** бесшовный слой капель 4–8 кадров 512×512; рябь/брызги 4 кадра 128×128. Лужи можно оставить программными.
3. **Ночь:** иконки луны/рассвета 96×96; новый фон не нужен.
4. **Охота:** иконка стаи 192×192. Новые кадры волка необязательны.
5. **Звуки:** тихий зацикливаемый дождь, короткий вой стаи, предупреждение ядерной поддержки и низкий стилизованный взрыв. Сейчас ядерный удар использует прежний звук взрыва; остальные события объявляются текстом. Новые звуки должны подчиняться общей громкости и выключению звука.

## Проверка и пределы

11 тестов: все враги/боссы, точные проценты, соответствие старой дневной симуляции и RNG, ночное усиление/рассвет, рывки, отсутствие событий в I, дождь, стая, ядерный удар, пауза, checkpoint/replay на 24 000 тиков через несколько циклов. Проверка восстановления использует разреженный обычный спавн: это проверка детерминизма, не нагрузки.

`PreviewHost` работает локально: тестовые 50 GE, без production API, билетов, реальных GE/лутбоксов и рейтинга. Упоминания наград в унаследованных карточках описывают основную игру; лаборатория наград не выдаёт. Герои открыты для проверки.

Протокол — `poultry-lab-difficulty-v1-20261113`. Для серверного переноса сложность закрепляется сервером в сессии/checkpoint вместе с версией движка и балансом. Старый replay-модуль от 12 ноября несовместим с новыми событиями. Не переносить `preview-host.js` в ranked. Production-интеграция и выкатка не выполнялись.

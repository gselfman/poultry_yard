# Архитектура и источники стиля

## Реализация

Автономные HTML/CSS/JS ES-модули, Canvas 2D, без сборки и сторонних зависимостей. Это позволяет быстро тестировать и позже встраивать мини-игру в web-оболочку QuRa.

- engine.js: состояние, движение, появление врагов, атаки, попадания, опыт, выборы, эволюции. Не зависит от DOM; random можно подменить для воспроизводимых тестов.
- game.js: отображение, ввод, камера, экранные состояния, звук и локальный рекорд.
- style.css/index.html: адаптивная оболочка и доступные HTML-кнопки.
- server.mjs: локальный сервер только на loopback:4173. Не предназначен для production.

Состояния: меню → playing ↔ paused; playing → upgrade → evolution (при пятом уровне) → playing; гибель → ended → новый забег/меню. Таймер останавливается во всех паузах. При потере фокуса/скрытии вкладки — пауза. Шаг ограничен 50 мс, чтобы возвращение к вкладке не перематывало бой.

Столкновения быстрых снарядов проверяются по отрезку между предыдущей и текущей позицией. Набор уже поражённых целей предотвращает повторный урон от прошивания. Умершие враги сразу исключаются из прицеливания и последующих попаданий.

Переиспользованы значения палитры: #fff2d4 (текст), #dbc4a1 (вторичный), #3b1c06 и #592e0a (поверхности), #ffb52e (золото), #ad661a (обводка), радиусы 12/20. Тёплые панели и золотая основная кнопка следуют этому языку. Это новая игровая сцена, не копия финансовых экранов QuRa. Курочки и враги пока нарисованы кодом, портреты выбора — системные emoji. Шрифт Onest используется при наличии, иначе системный; бинарные ресурсы приватного QuRa не публиковались в публичный poultry_yard.

## Будущая интеграция

Сохранить отдельный игровой движок. Авторизацию, баланс GE, идемпотентное списание за переброс, выдачу наград и валидацию рекордов подключать через backend QuRa. Текущим localStorage и клиентским очкам доверять нельзя. Пока нет сетевых вызовов к QuRa, платежей и реальных списаний.

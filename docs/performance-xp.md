# Проверка опыта и итерация анимаций

Измерения выполнены в облачном Chrome на canvas1200×800. Это отдельный слой XP, не FPS всей игры и не гарантия для телефона. Три прогретых прогона, принудительное завершение canvas через readback. Исходный и исправленный рендер доступны для воспроизведения в perf.html.

| Семечек в мире | Старый рендер, мс | Кэш без отсечения, мс | Кэш + отсечение, мс | Видимых |
|---|---:|---:|---:|---:|
|1000|35.6|4.0|1.4|49|
|10000|221.0|33.8|8.5|318|

Градиент и размытие больше не создаются для каждой семечки на каждом кадре: используются3 кэшированных изображения. Вне камеры семечки не рисуются. В симуляции используются квадраты расстояний и сбор с уплотнением того же массива; опыт не исчезает, не урезается и не объединяется. Магнит собирает всю ценность.

Node-тест шагов симуляции (240 шагов, фиксированный набор, без врагов): при30000 семечек среднее2.44→0.32мс, p953.47→0.55мс. Значения зависят от прогрева и среды; это не измерение GC в браузере. Отдельной heap/GC трассы не снималось.

Сглаживание и кэш смешанных кадров удалены полностью. Белки42→30HP. Исправлены стороны крыльев, фиксирован угол лапы/топота, аура желудя приглушена и кэшируется.

Анимации утки, гуся и Цесарки извлекаются из существующих Figma PNG без удаления фона. Индюк остаётся на старом игровом спрайте до восстановления оригинального листа: уменьшенный обзор не используется вместо оригинала. Существующие повреждённые материалы не заменяются автоматически.

Пульт под игровым полем: 174 числовых параметра героев, оружия, пассивок, врагов, расписания, бюджета и состава спавна, роста сложности, защиты, выпадений, ближних атак и эволюций. Доли: 0.12 = 12%, 0.005 = 0.5%.

Настройки применяются при вводе допустимого значения. Скорость и пассивки пересчитываются сразу. Базовые HP/скорость/радиус врагов меняют существующих врагов; при изменении базового HP сохраняется доля здоровья. Новые атаки получают новые параметры; уже выпущенные снаряды и начавшиеся анимации завершаются с прежними. Формулы роста врагов применяются к новому спавну. Начальное число сфер применяется при новом забеге. Расписание меняет будущий спавн, существующие враги не удаляются.

Сохранение баланса в localStorage, экспорт/импорт JSON и сброс к базе 0.6. Сборка, таймер и тестовые переключатели в JSON не входят. У посетителей независимые настройки; общего серверного редактора нет.

Тестовые инструменты: неуязвимость, автовыбор карточек, лечение, очистка врагов, выпуск вида, смена времени, уровни/эволюции орудий и число пассивок. Тестовая сборка разрешает эксклюзивные орудия у других героев для проверки комбинаций; обычный случайный выбор сохраняет ограничения. До трёх орудий. Мини-окно при прокрутке можно отключить кнопкой.

Предел врагов по умолчанию 600, настраивается. Экстремальные комбинации могут увеличивать нагрузку.

48 тестов: 43 исходных и 5 новых проверок живых параметров урона/скорости, расписания, ближнего боя и лимита спавна. В браузере проверены старт, применение скорости 126 → 200, поиск и ручной спавн. Полный десятиминутный плейтест человеком и физический телефон не проверены.

# Недостающая графика и техническая доводка

## Новые изображения, необходимые для запуска

Обязательной новой генерации нет. Меню — B03 и утверждённые герои; загрузка — золотое яйцо S01-07 + полоса S06; правила — S01/S02/S07; настройки — toggle-on/off из `gselfman/volk_lovit/prototype/dist/assets/ui`; пауза, результат и воскрешение — те же панели. Название «Птичий двор» — живой Onest Bold 700 на F03, исходный QuRa отдельным слоем. Генерировать новый логотип QuRa не нужно.

## Технические замечания

21 из 22 исходных файлов найдены в Figma по точному SHA1/imageHash. Второй вариант F02 добавлен как уменьшенное JPEG-превью (node 36:2), поскольку прямой импорт исходного PNG был отклонён каналом загрузки; полный PNG сохранён в `assets/design/F02-second-original.png`. Это не производственный компонент.

Фактические размеры листов меньше запрошенных 4K: большинство квадратных 1254×1254, широких 1448×1086. Нарезка сохраняет исходные пиксели, без искусственного увеличения. S09, S11 и S12 — референсные листы: совмещение кадров, силуэтов и границ требует ручной проверки. Для боя сохранены одобренные v5/v7 и программные эффекты. Изображение не превращается в качественную анимацию только после разрезания.

S03 имеет геометрические сдвиги между состояниями, S02 — отличия силуэтов между обычными и выбранными версиями. Для прототипа фокус и нажатие задаются программно/векторно поверх одной геометрии. B01 пока не сертифицирован как бесшовный: в большой карте требуется проверка стыков на повторе 3×3.

## Общий префикс для исправлений

Единый стиль QuRa: детальная мультяшная живопись, мягкий убедительный объём, округлые читаемые формы, тёплое золото с янтарными тенями, кремовые и оранжевые акценты. Свет сверху слева. Читаемость в малом размере, умеренная детализация. Не фотореализм, не плоский вектор, не пиксель-арт, не холодный неон. В качестве строгих референсов приложить текущие утверждённые ассеты.

## P01 · Боевые эффекты — исправленная версия S09

Один прозрачный PNG 4096×4096, 4×4, каждая ячейка 1024×1024. Ряд 1: контактное попадание — появление, пик, распад, затухание. Ряд 2: компактный взрыв яйца/патрона — те же четыре фазы. Ряд 3: топот — малое низкое эллиптическое кольцо, раскрытие, широкое кольцо, растворение. Ряд 4: защита — слабое тонкое кольцо, усиление, пульс, затухание. Единый центр (512,512) и опорная точка внутри каждой ячейки. Все пиксели, включая полупрозрачное свечение и частицы, только внутри области 160–864 px по обеим осям. На границе этой области alpha строго 0. Не рисовать соединённых между кадрами шлейфов. Попадание — золотистая искра; взрыв — янтарная вспышка и несколько кремовых осколков; топот — лёгкая пыль с пустым центром; защита — тонкий контур, не пузырь. Без текста, сетки, фона, персонажей, густого дыма и огня по земле. Истинный alpha. Каждый кадр — самостоятельный изолированный спрайт.

## P02 · Пять врагов — отдельная генерация по одному виду

Повторить для крысы, лисы, белки, волка, медведя, с приложенным утверждённым v7 конкретного вида. Один лист 3072×1024, три равные ячейки: покой, шаг A, шаг B. Строго сохранить лицо, цвет, пропорции, хвост и характер исходника. Слегка верхний ракурс, взгляд вправо. Разница только в положении лап и малом переносе веса, без изменения масштаба, длины тела и размера головы. Во всех кадрах точка между опорными лапами на одной высоте; сохранить одинаковую рамку и центр массы. Полный силуэт вместе с хвостом внутри центральных 70% каждой ячейки. Между кадрами полностью прозрачный разрыв. Без земли, жёстких теней, реквизита, крови, новых костюмов. Истинный alpha; без текста и сетки. Для белки сохранить только её существующий жёлудь.

## P03 · Панель с корректной прозрачностью F02

Одна пустая фронтальная панель 3072×2048. Тёмное полированное дерево, тонкий медово-золотой объёмный кант, небольшие завитки в четырёх углах. Внутренний центр непрозрачный и спокойный для кремового текста Onest; верхняя зона под заголовок, центр под три отдельные карточки, низ под кнопку. Все украшения за пределами полезной зоны. ВНЕ ВНЕШНЕГО СИЛУЭТА панели alpha строго 0: никакого коричневого прямоугольника, студийного фона, шахматки и дымки. Не рисовать карточки, кнопки, текст, логотип, персонажей, разделители и награды. Полный силуэт, поля минимум 120 px. Можно не генерировать, если подходит имеющийся `ui/panel` из Волка.

## P04 · Рэмбо в полном обвесе — только если нужен новый игровой ракурс

Приложить утверждённый `chicken/commando/idle` из Figma. Один лист 4096×1024, четыре кадра одного героя: покой, шаг A, проходная фаза, шаг B. Чёрная боевая курочка с красной повязкой, полным боекомплектом и существующим пулемётом; строго сохранить оружие, патронные ленты, лицо и пропорции исходника. Взгляд вправо, слегка верхний игровой ракурс, не портрет. Малые шаги, оружие удерживается одинаково, без самостоятельной стрельбы. Одинаковая опорная точка лап, неизменные масштаб и длина оружия, полный силуэт в центральных 70% каждой ячейки. Истинный alpha, без земли, гнезда, текста, рамок, букв и чужих маркировок. Для макета уже используется утверждённый исходник; новая генерация не обязательна.

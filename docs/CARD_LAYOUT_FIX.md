# Исправление раскладки карточек · 03.11.2026

Причина: при ширине до 740px и небольшой высоте горизонтального окна правило `.upgrade.passive-card` оставляло display:grid из мобильного режима, а менее специфичное landscape-правило `.upgrade` не могло заменить его на flex. При наведении `.upgrade:hover` имел достаточную специфичность и переключал раскладку. Поэтому текст становился ровным только под курсором. Отдельно hover-селекторы могли влиять на раскладку мобильных эволюций.

Все структурные правила карточек теперь используют один селектор `.cards > .upgrade` с одинаковой специфичностью на каждом breakpoint. Hover меняет только цвет/границу. В landscape явно восстановлены align-items:stretch, text-align:left и одинаковые промежутки. Для дочерних блоков заданы безопасные min/max-width и перенос длинных слов.

Проверено в Chrome на fixture с «Зорким глазом», «Щедрым залпом», «Боевым нравом»:
- 700×390: все карточки flex, 198×341px, одинаковы до/после hover, горизонтального переполнения нет.
- 390×744: grid, одна колонка карточек; переполнения текста нет.
- 144 Node-теста, включая запрет структурных изменений в hover-правилах карточек.

Серверному агенту: перенести актуальный `ui-refresh.css` из ветки `ui/readability-2026-11-02` / PR #5 поверх UI-релиза. Не переносить QA fixtures в runtime. После сборки обновить кеш CSS/версию статики, проверить 700×390 и телефон без мыши. JS движка, баланс, награды и интеграционный адаптер не менялись.

# Выкат UI-обновления «Птичьего двора» · 02.11.2026

## Что изменено

- Мир отображается с `VIEW_ZOOM=1.3`: курочка, все враги, снаряды, предметы и области столкновений на экране +30%. Координаты мира, HP, радиусы физических тел, скорость и урон не менялись. Камера показывает меньший участок большого поля; телефонная дистанция белки проверяется прежними тестами.
- Семечки опыта дополнительно увеличены (маленькие 16→22, средние 23→30, большие 33→42 мировых пикселя) с сохранением различий ценности; контрастная тень и существующий свет кэшируются один раз на тип. Вместе с камерой предметы опыта визуально больше прежних примерно на 65–79%.
- Трава приглушена одним закэшированным слоем, декор менее контрастный. Ауры врагов не добавлялись; оригинальные изображения/анимации сохранены.
- Крупные портреты и орудия героев, сердца-ассеты, читаемая Onest-типографика. На телефоне — одна крупная карточка, соседняя частично видна; кнопки переключения и свайп. Закрытых героев можно посмотреть, начать ими нельзя.
- Отдельные смысловые строки, крупные числа «до → после» для улучшений, натуральные переносы описаний. Карточки адаптивные, вертикальная графическая рамка не растягивается горизонтально.
- Боевой HUD: изображения оружия и уровни, отдельные очки/время/уровень. Сердца и слоты не создаются заново без изменения данных. Заголовки босса читаемее; числовое HP по-прежнему скрыто на экране.
- Компактные настройки с одинаковыми переключателями звуков/радио и громкостью. Короткие правила с картинками. В паузе — сборка, остальная статистика раскрывается. Завершение вручную подтверждается и имеет собственную подпись на итогах.
- Добавлены описание и изображение для каталога мини-игр: `docs/MINIGAME_CATALOG.md`, `integration/minigame-catalog.json`, `assets/catalog/poultry-yard-gameplay.jpg`.

## Действия серверного агента

1. Прочитать актуальные `AGENTS.md`, `CLAUDE.md`, `docs/AGENT_LOOP.md` QuRa и ранее подготовленный `docs/PRODUCTION_HANDOFF.md` игры. Работать в отдельной ветке, соблюдать review/needs-owner/deploy gates.
2. Если игра ещё не интегрирована — брать ветку с PR #4 + этим UI-обновлением и реализовать host adapter по инструкции. Если уже интегрирована — перенести UI и camera/render diff **поверх существующего адаптера**. Нельзя целиком заменить адаптированный `game.js` прототипным файлом: это вернёт тестовые GE/localStorage и отключит session/replay hooks.
3. Не менять seed/баланс/кошелёк/каталог лута при визуальном обновлении. Запрет публичного пульта и обязательные подтверждения GE сохраняются. Runtime production gate не снимать ради показа нового UI.
4. Зарегистрировать карточку игры в `web/app/game/v1/GameViews.tsx`, `PlayView()` рядом с Волком; перечитать актуальный код. Взять тексты и JPEG из `MINIGAME_CATALOG.md`, реальный game route — из адаптера, а билет/цену/доступность — из bootstrap. Не обещать реальные GE/XP из прототипа.
5. Из root standalone репозитория выполнить:

```bash
node --test tests/*.test.mjs
node build-runtime.mjs
node scripts/verify-release.mjs build
node build-runtime.mjs --production
node scripts/verify-release.mjs build-production
```

В Site checkout тесты находятся в `dist/tests`. `build-runtime` сам различает root/dist layout. Обе сборки содержат шрифты, UI и превью каталога; production остаётся fail-closed до готовности интеграции.

6. Статику выкатывать в новый versioned release folder и переключать атомарно. Сохранить предыдущий релиз для отката. Для активных забегов не подменять закреплённые engine/config versions. Сборку Next и перезапуски выполнять по текущим правилам QuRa; соседние сервисы не затрагивать.
7. Проверить реальные телефоны: 360×740, 390×844, горизонтальный экран; safe areas и панели браузера, scroll описаний, переключение закрытых героев, joystick/pointer release, подтверждения GE, радио on/off/volume, видимость белки и контуров босса с новым масштабом. Пространство обзора уменьшилось из-за приближения камеры — проверить атаки с краёв.
8. Проверить длительную плотную волну на устройстве: UI-обновление не является сертификацией 60 FPS. Предыдущие ограничения браузерного профиля из DEPLOY_READINESS.md остаются актуальны. Не обещать решённые GPU/GC/мерцание без замеров.

## Проверки этой версии

143 Node-теста пройдены. В Chrome проверены реальные menu/settings/pause flows и отдельные layout fixtures для 360/390 px. Fixed fixture использует те же шаблоны, renderer, камеры и ассеты, но не подтверждает touch UX на физическом телефоне. Скриншот каталога — изображение подготовленной сцены на движке игры, без генерации изображения нейросетью и без привязки к реальному рекорду пользователя.

В отчёте о выкате указать commit/PR, URL, CI, какие устройства проверены и подключена ли реальная экономика. Публичный прототип и prod qura.one — разные места публикации.

# QuRa «Птичий двор» — контекст для продолжения (2026-10-29)

## Проект
- GitHub: https://github.com/gselfman/poultry_yard, ветка `main`.
- Автономный браузерный survival-рогалик Canvas 2D / ES-модули; Node.js 20+, запуск `node server.mjs`, тесты `node --test tests/engine.test.mjs`.
- Персонажи: Ряба (яйца), Рэмбо (АК), Монах (крылья и лапки); три слота орудий, пассивные улучшения, эволюции, цель выжить 10 минут и бонусная бесконечная волна.
- В проекте тестовые GE и локальный рекорд; **реальной авторизации, платежей и соединения с QuRa нет**. Основной репозиторий QuRa не менять.
- Предыдущий базовый коммит: `fbba957`, v0.6; новые враги и боевые спрайты в `assets/v7`, персонажи в `assets/v5`.

3. Не допускать неправильного переворота красных боевых эффектов.
4. Умерить свечение желудей.
5. Проверить и уменьшить рывки / просадки плавности, не ломая геймплей.
6. Пока не добавлять новые механики.

## Важные ограничения и что проверять
- Ссылка на старую общую переписку недоступна автоматическому чтению; это восстановленный контекст из доступных последних сообщений и текущего кода, а не дословный экспорт.
- Требуется проверка в браузере: направления обоих крыльев и топота, отсутствие перевернутых эффектов; визуально сравнить яркость желудей.
- Требуется реальное профилирование FPS/long tasks на слабом устройстве при большом числе врагов. Оптимизация буфера снижает выделение памяти, но не гарантирует устранение рывков. Сортировка и отрисовка большого числа спрайтов по-прежнему выполняются каждый кадр.
- Прогнать `node --test tests/engine.test.mjs`, проверить запуск `node server.mjs`, см. `docs/QA.md`. Из этого сеанса реальный запуск/браузерные тесты не подтверждены.
- Не путать с отдельной мини-игрой QuRa «Волк ловит яйца» (`gselfman/QuRa`): это другой прототип.

# Игровая графика v1

Создана для «Птичьего двора» 24.10.2026 с ImageGen. Визуальное направление: тёплая сказочная ферма QuRa, мягкий объём, детальная шерсть/перья, дерево, солома и золотистый свет. Ориентир — просмотренный референс карточки Рябы и палитра QuRa. Из приватного репозитория QuRa бинарные ресурсы не копировались.

- yard-v1.png — вид сверху, двор без игровых препятствий.
- ryaba-v1.png, rambo-v1.png — герои, используются также на карточках выбора.
- rat-v1.png, fox-v1.png, wolf-v1.png, bear-v1.png, squirrel-v1.png — враги.

PNG персонажей имеют прозрачный фон. В игре сохраняется соотношение сторон, направление движения отражает рисунок; процедурные тени, мерцание, предупреждение рывка и индикаторы здоровья рисуются поверх арены. Покадровые анимации героев и пяти зверей подключены из assets/animation; нормализованные боевые спрайты — из assets/combat. У гуся, утки, Цесарки и Индюка пока одиночные позы. Радиусы столкновений независимы от декоративных деталей спрайта.

Неудачные промежуточные листы characters-v*.png игнорируются Git и не используются игрой.

## Промпты

Общая часть: Production 2D game sprite on true transparent alpha background. A single full-body subject, facing right in a three-quarter overhead game view. Semi-realistic painted fantasy farm style, soft volume, restrained detailed feathers or fur, natural anatomy, crisp readable silhouette. Not a flat vector, not a childish cartoon, not chibi. No background, no ground, no lettering, no big halo. Leave transparent padding.
